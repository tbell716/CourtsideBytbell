# Courtside Client

Official customer downloads and signed automatic updates.

Download Courtside-client-update.zip from the latest release, extract all four files, and run Courtside Client.exe. Windows x64 and the .NET 9 Desktop Runtime are required.

Sign in with Discord to use the free Player controls. Enter your Courtside+ activation key in Settings to unlock paid features.

Existing clients can click Update Ready. The legacy Courtside-update.zip is provided only for compatibility with older automatic updaters.

Support: https://discord.gg/Mm5Kt5fmvs

Source code, signing keys and Owner access keys are not stored in this repository.
